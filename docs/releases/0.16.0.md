# XMQR client 0.16.0 — opções de sessão MQTT 5 (experimental)

C66/C67 acrescentam `--clean-start true|false` e
`--session-expiry-seconds 0..4294967294|never` em `pub|sub --protocol-version 5`.
Use um ClientID estável para solicitar retomada. O client rejeita CONNACK que
indica sessão anterior após Clean Start. O padrão MQTT 3.1.1 e
`--clean-session` permanecem separados.

**Limites:** um novo processo do client não restaura seus próprios fluxos QoS
pendentes. Will MQTT 5, lotes, reconexão MQTT 5, propriedades avançadas e
flow control completo continuam pendentes; as fases 6A–6D seguem abertas.
ACK de publicação confirma protocolo, não processamento de negócio.

Ubuntu 26.04 amd64: confira SHA-256 e manifesto da prerelease, faça backup de
configuração/segredos e instale o `.deb` numerado. Para rollback, pare as
unidades e reinstale 0.15.0 preservando perfis e segredos. A tag Docker
`latest` não é movida; o pacote não é instalado no WSL do operador.

Validação: gates Rust, testes unitários/wire e integração com broker 0.18.0 e
Mosquitto 2.0.22. Registros [C66](../../prompts/registros/C66-sessao-mqtt5-zero-infinita.md)
e [C67](../../prompts/registros/C67-expiracao-finita-sessao-mqtt5.md).
