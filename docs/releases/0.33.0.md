# XMQR client 0.33.0 — WSS mTLS local (candidato)

C114 habilita `--ws-url wss://127.0.0.1:PORTA/mqtt` (ou `[::1]`) para pub/sub MQTT 3.1.1/5 no modo seguro, com CA/SAN e certificado/chave cliente existentes. O usuário/senha MQTT continua por prompt ou arquivo privado. A URL exige IP loopback, porta e caminho sem userinfo, query ou fragmento; `--host`/`--port`, perfil, TLS-senha e estado durável sobre URL são recusados. WS `open-lab` e TCP/TLS permanecem.

O broker P212 em `main`, candidato a 0.40.0, fornece WSS mTLS local. Integração cruzada TCP/WSS, ACL e negativos de senha/CA passaram; navegador e acesso remoto seguem fora deste recorte. Sem migração dos manifestos duráveis.

**Distribuição:** C115 exige CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável, imagem numerada por digest, tag e prerelease com seis anexos e SHA-256 remoto. Registrar os resultados antes de declarar publicado. O WSL instalado do operador não é alterado. Ubuntu 24.04, arm64, Windows nativo e fases globais 6A–6D/7–9 continuam abertas.
