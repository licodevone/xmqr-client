# XMQR client 0.42.1 / bridge 0.4.0 — prerelease corretiva publicada

C144 rejeita NUL em tópico/User Property, VBI redundante e flags MQTT 5
reservadas inválidas antes de entregar mensagem ou confirmar sucesso.
Payload/Correlation Data binários, Unicode/BOM e decoder MQTT 3.1.1 continuam
preservados. As cinco correções obrigatórias P232 da 0.42.0 também estão presentes.
Bridge 0.4.0 mantém origem MQTT 5/QoS 2 e destino MQTT 3.1.1; fase 8 aberta.

## Instalação e rollback

Pacote Ubuntu 26.04 amd64; imagem Debian Bookworm Linux/amd64 não root.
Antes de atualizar, pare as instâncias desejadas e guarde configuração e estado
privados com serviços parados. Confira os sidecars SHA-256 baixados da mesma
release. Depois, no Ubuntu:

```text
sha256sum -c xmqr-client_0.42.1-1_amd64.deb.sha256
sudo apt install ./xmqr-client_0.42.1-1_amd64.deb
mqtt-client --version
mqtt-bridge --version
```

Saídas esperadas: `mqtt-client 0.42.1` e
`mqtt-bridge 0.4.0 (xmqr-client 0.42.1)`. O pacote não inicia/habilita serviços;
revise a configuração antes de iniciar as instâncias. Não há migração de estado.
Se um servidor passar a falhar, corrija os pacotes inválidos enviados por ele.

Rollback: pare as instâncias e instale o `.deb` 0.42.0 verificado usando
`sudo apt install --allow-downgrades ./xmqr-client_0.42.0-1_amd64.deb`.
Formatos/identidades duráveis são os mesmos, porém as quatro validações de C144
deixam de existir. Preserve os diretórios pendentes; não apague estado para
contornar recusa de sessão. Não se testa rollback no host do operador.
