# XMQR client 0.26.0 — Will MQTT 5 (experimental)

C94 permite Payload Format Indicator, Content Type, Response Topic, Correlation Data e User Property repetida no Will MQTT 5. C95 acrescenta `--will-message-expiry-seconds 0..4294967295`. As opções exigem Will completo e protocolo 5; são distintas das propriedades de PUBLISH. Broker 0.29.0/P163–P164 é o par validado: o prazo começa quando o Will é publicado, inclusive depois do atraso e de reinício.

**Instalação e rollback:** preserve perfis e segredos; para voltar ao client 0.25.0, pare as unidades e reinstale o pacote anterior. O estado MQTT v15 pertence ao broker; um rollback do broker 0.29.0 para 0.28.0 requer backup privado v14 anterior.

**Distribuição:** tag anotada, prerelease, pacote Ubuntu 26.04 amd64, imagem numerada e manifestos após CI do commit exato e conferência de SHA-256/digest. O [registro C96](../../prompts/registros/C96-release-0.26.0.md) documentará hashes. WSL do operador e Docker `latest` não são alterados. Fases globais seguem abertas.
