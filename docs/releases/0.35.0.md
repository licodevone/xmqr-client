# XMQR client 0.35.0 — outbox QoS 1 por WSS mTLS (candidato experimental)

C119 permite publicação MQTT 5 QoS 1 com outbox privada por URL WSS mTLS local/remota. A URL canônica distingue o journal do destino TCP sem alterar esquema; outra URL é recusada. C120 verificou retransmissão com mesmo Packet ID e DUP=1 após PUBACK perdido quando Session Present=1; Session Present=0 preserva a operação sem reenvio. [Aceites C119](../../prompts/registros/C119-wss-qos1-outbox.md) e [C120](../../prompts/registros/C120-wss-qos1-outbox-recovery.md).

O client 0.34.0 mantém os journals existentes, mas recusa outbox por URL. Fazer backup privado antes de downgrade. WS aberto, QoS 2 e assinatura persistente por URL continuam recusados. Broker 0.42.0/P216 é o par planejado. Publicação, hashes e rollback dependem dos gates do [prompt C121](../../prompts/clients/121-release-0.35.0.md). Navegador real e fases globais 6A–6D/7–9 permanecem abertos.
