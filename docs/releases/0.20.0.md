# XMQR client 0.20.0 — metadados de PUBLISH MQTT 5 (experimental)

C77/C78 acrescentam ao `pub --protocol-version 5` Payload Format Indicator, Content Type, Response Topic, Correlation Data hexadecimal e User Property repetível. A CLI rejeita valores inválidos antes de conectar, preserva a ordem dos pares e permite nomes repetidos. `--payload-format 1` exige payload UTF-8 válido. O padrão da CLI continua MQTT 3.1.1.

**Limites:** `sub` ainda exibe tópico e payload sem os metadados. Publicação com Topic Alias e retomada automática dos fluxos QoS do próprio client ainda não estão cobertas. O broker parceiro 0.22.0 grava estado v10; rollback dele para 0.21.0 exige backup privado v8 anterior à migração. As fases 6A–6D e 7–9 seguem abertas; não há alegação de conformidade MQTT 5 integral.

Ubuntu 26.04 amd64: confira manifesto e SHA-256 da prerelease, preserve perfis/segredos e instale o `.deb` numerado. Para rollback do client, pare a unidade e reinstale 0.19.0 preservando perfis. Docker `latest` permanece intacta. Este release não instala nada no WSL do operador.

Validação prevista: gates Rust, parser/wire, TCP real com broker P142 e Mosquitto, pacote e CI. Evidências: [C77](../../prompts/registros/C77-publish-payload-format-content-type-mqtt5.md), [C78](../../prompts/registros/C78-publish-request-properties-mqtt5.md) e [P142](../../../xmqr/prompts/registros/P142-publish-request-properties-mqtt5.md).
