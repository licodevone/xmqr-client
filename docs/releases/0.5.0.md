# XMQR Client 0.5.0 — experimental

Integração com systemd e instalação por pacote Ubuntu26.04 amd64.

- SIGTERM/SIGINT tentam DISCONNECT limitado, sem reconectar no encerramento.
- Templates opcionais xmqr-client-sub@ e xmqr-client-pub@; assinatura com
  reinícios limitados e publicação oneshot sem reenvio automático.
- Usuário dedicado e senha em arquivo privado; TLS/mTLS e limites preservados.
- Deb, documentação de instalação/upgrade/remove e CI Linux adicionados.

Validação Ubuntu26/WSL:44 testesRust, incluindo SIGTERM wire real; fmt/Clippy,
build e inventário aprovados. Integração systemctl/mTLS com XMQR próprio:
assinatura/publicação, reload/restart broker e stop do client aprovados com
units isoladas e usuário não root. Deb instalado/atualizado/removido em
containerUbuntu26; credenciais externas preservadas. Compilação Windows aprovada.

Baixe deb/checksum juntos, verifique com `sha256sum -c`, depois:

```sh
sudo apt install ./xmqr-client_0.5.0-1_amd64.deb
mqtt-client --version
```

Serviços não iniciam automaticamente. Configure cada instância conforme
docs/ubuntu-systemd.md. Pub não reinicia: repetir start pode duplicar dados;
ACK não comprova processamento de negócio. Upgrade exige start explícito.

Experimental:sem produção, Ubuntu24/arm64 ou MSRV1.88 exato comprovados.
Persistência MQTT local e retomada QoS2 interrompida continuam limitadas.
Ainda não existe repositório APT próprio assinado; use deb local.
