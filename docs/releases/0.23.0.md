# XMQR client 0.23.0 — Subscription Identifier MQTT 5 (experimental)

C87 adiciona `sub --protocol-version 5 --subscription-identifier N`, com N de 1 a 268435455. O client inclui o identificador no SUBSCRIBE, recusa CONNACK que anuncie indisponibilidade e mostra os identificadores recebidos em `metadata.subscription_identifiers` do JSONL, mantendo repetições. Mosquitto 2.0.22 foi validado com filtro simples e dois filtros sobrepostos; o broker XMQR parceiro requer P150/0.25.0. MQTT 3.1.1 continua padrão e o client não retoma automaticamente o fluxo QoS MQTT 5 local.

**Instalação e rollback:** `.deb` Ubuntu 26.04 amd64 e imagem numerada foram publicados após C88. Preserve perfis/segredos; para voltar a 0.22.0, pare a unidade e reinstale o pacote anterior. Confira manifesto e SHA-256 dos anexos. O processo de release não altera a instalação WSL do operador e não move Docker `latest`.

Fases 6A–6D e 7–9 seguem abertas; não se declara conformidade MQTT 5 integral. [Evidência C87](../../prompts/registros/C87-subscription-identifier-mqtt5.md).
