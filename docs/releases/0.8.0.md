# xmqr-client 0.8.0 — filtros retained

O assinante pode omitir o replay retained com `--ignore-retained` ou exibir
somente publicações recebidas com RETAIN=true com `--retained-only`.
Sem essas flags, o comportamento anterior é preservado. `--count` conta
mensagens exibidas; mensagens filtradas continuam completando QoS1/2.

As flags são exclusivas e somente para sub. Publicações ao vivo normalmente
chegam RETAIN=false mesmo quando o publicador usou retain; o filtro considera
a flag wire, sem inferir o estado armazenado. TLS/SAN, quotas e ACL preservados.

Validação: Ubuntu26/WSL52 testes Rust (30unit+22wire), Windows51 (30unit+21wire),
fmt, Clippy e build; integração real retained/live nos três QoS e4 regressões
C27 incluindo peerTLS/negativos. Ciclo debUbuntu26amd64 install/upgrade/rollback/
remove/purge aprovado em container descartável. ZIPWindows/TARLinux extraídos,
versão/hash conferidos. Nenhum serviço instalado foi operado.

Distribuição experimental: debUbuntu26amd64, TARLinuxamd64 e ZIPWindowsamd64,
com SHA-256. A imagem Docker0.7.1 anterior não contém estes filtros; nenhuma
imagem nova é anunciada nesta release. Sem APT, arm64, MQTT5 ou WS/WSS.

Evidência: [registro C41](../../prompts/registros/C41-filtros-retained.md).
