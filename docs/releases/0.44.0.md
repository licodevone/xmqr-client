# XMQR Client 0.44.0 — candidato experimental

- **C154** adiciona `mqtt-client probe` para diagnosticar conexão MQTT
  3.1.1 e 5, assinatura de tópico exato e entrega de uma mensagem QoS 0
  de teste quando solicitada. O resultado JSON omite dados privados.
- **C153** inclui `mqtt-client --check-config pub|sub`, que verifica as
  opções e o material local antes de abrir uma conexão.
- **C156** inclui `mqtt-client bench` para conexões mantidas, duas ondas
  de reconexão e entregas QoS 0. O limite do gerador é de 1.000 clientes
  de teste. Vazão e latência dependem do cenário medido.
- A base Windows posterior a 0.43.0 inclui o adaptador opt-in do serviço
  e os controles privados de credenciais e saída NDJSON.
- `mqtt-bridge` mantém a versão funcional 0.5.0. Os novos comandos de
  diagnóstico não exigem migração de estado. Para rollback, preserve
  configurações e dados privados e pare os serviços afetados antes de
  trocar os binários. As versões do Broker e do Admin são independentes.

O candidato aguarda CI Ubuntu, validação do Windows Service, wire MQTT,
pacote/imagem e checksums. A tag prevista é `v0.44.0`.
