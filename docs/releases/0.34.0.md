# XMQR client 0.34.0 — perfil WSS e acesso remoto explícito (prerelease experimental)

C116 aceita `ws_url` WSS mTLS no perfil TOML v1 e precedência de `--ws-url`; C117 exige `--allow-remote-wss` para URL fora de loopback. CA/SAN, certificado/chave cliente, senha MQTT e subprotocolo `mqtt` continuam necessários; não há fallback WS aberto. O broker P214/0.41.0 é o par previsto. [Aceite C116](../../prompts/registros/C116-wss-mtls-profile.md) e [C117](../../prompts/registros/C117-remote-wss-mtls-client.md).

Sem migração dos manifestos duráveis. O client 0.33.0 lê os mesmos dados, mas não inclui perfil WSS nem acesso remoto. [C118](../../prompts/registros/C118-release-0.34.0.md) validou CI da fonte exata, pacote Ubuntu 26.04 amd64, rollback descartável, imagem por digest remoto e seis anexos com hash remoto. O WSL instalado do operador não foi alterado. Navegador, estado durável por URL e fases globais 6A–6D/7–9 seguem abertos.
