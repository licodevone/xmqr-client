# XMQR client 0.27.0 — Client Identifier atribuído (experimental)

C97 solicita ID MQTT 5 ao broker e exige a propriedade `0x12` válida no CONNACK. C98 permite reutilizar um ID longo em `--client-id`; C99 permite criar uma sessão com expiração finita ou infinita. Para o broker 0.30.0/P166, use `--protocol-version 5 --server-assigned-client-id --session-expiry-seconds 60`, guarde o ID de stderr e reconecte com `--client-id ID --clean-start false --session-expiry-seconds 60` antes do vencimento. A CLI não salva estado QoS local e não promete IDs longos com qualquer broker externo.

**Instalação e rollback:** preserve perfis e segredos; para voltar ao client 0.26.0, pare as unidades e reinstale o pacote anterior. O estado MQTT v15 pertence ao broker e não muda nesta entrega; um rollback do broker a 0.28.0 ainda requer backup privado v14 anterior.

**Distribuição:** [prerelease v0.27.0](https://github.com/licodevone/xmqr-client/releases/tag/v0.27.0) publicada após [CI do commit exato](https://github.com/licodevone/xmqr-client/actions/runs/39022714234), pacote Ubuntu 26.04 amd64, ciclo descartável de upgrade/rollback e imagem numerada executada por digest. Os 6 anexos tiveram tamanho e SHA-256 remotos conferidos; [C100](../../prompts/registros/C100-release-0.27.0.md) registra hash e digest. WSL do operador e Docker `latest` não foram alterados. Não há homologação Ubuntu 24.04, arm64 ou Windows nativo. Fases 6A–6D e 7–9 continuam abertas.
