# XMQR client 0.32.0 — WebSocket MQTT de laboratório (candidato)

C112 habilita `--ws-url ws://127.0.0.1:PORTA/mqtt` (ou `[::1]`) somente com `--open-lab`, para `pub` e `sub` MQTT 3.1.1/5. A URL exige IP loopback, porta e caminho, sem usuário/senha, query ou fragmento. O upgrade exige subprotocolo `mqtt`. Não há WSS, perfis WS ou estado durável sobre URL WS. TCP/TLS continuam disponíveis.

O broker XMQR publicado 0.38.0 ainda não contém listener WS; P210 em `main` fornece o par local sob `MQTT_WS_BIND`, candidato ao marco broker 0.39.0. O listener do broker recusa `Origin`, portanto este recorte é para CLI local, sem navegador. Fase 7 global permanece aberta.

**Distribuição:** C113 exige CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável, imagem numerada por digest, tag e prerelease com seis anexos e hashes remotos. Registrar resultados antes de considerar este candidato publicado. O WSL instalado do operador não é alterado; Ubuntu 24.04, arm64 e Windows nativo ainda não estão homologados.
