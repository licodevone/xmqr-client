# XMQR client 0.32.0 — WebSocket MQTT de laboratório (experimental)

C112 habilita `--ws-url ws://127.0.0.1:PORTA/mqtt` (ou `[::1]`) somente com `--open-lab`, para `pub` e `sub` MQTT 3.1.1/5. A URL exige IP loopback, porta e caminho, sem usuário/senha, query ou fragmento. O upgrade exige subprotocolo `mqtt`. Não há WSS, perfis WS ou estado durável sobre URL WS. TCP/TLS continuam disponíveis.

O broker XMQR 0.39.0 fornece o par local sob `MQTT_WS_BIND`. O listener recusa `Origin`, portanto este recorte é para CLI local, sem navegador. Fase 7 global permanece aberta.

**Distribuição publicada:** [prerelease v0.32.0](https://github.com/licodevone/xmqr-client/releases/tag/v0.32.0), CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável e imagem numerada por digest passaram. Os seis anexos tiveram tamanho e SHA-256 remotos conferidos no [registro C113](../../prompts/registros/C113-release-0.32.0.md). O WSL instalado do operador não foi alterado; Ubuntu 24.04, arm64 e Windows nativo ainda não estão homologados.
